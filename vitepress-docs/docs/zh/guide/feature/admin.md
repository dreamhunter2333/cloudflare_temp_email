# 管理后台

> [!NOTE]
> 需要配置 `ADMIN_PASSWORDS` 或者 `ADMIN_USER_ROLE` 才可以访问管理后台
> 管理员角色配置：如果用户角色等于 `ADMIN_USER_ROLE`，则可以访问管理后台

部署前端应用之后，点击左上角 logo 5 次或访问 `/admin` 路径即可进入管理后台。

需要在后端配置 `ADMIN_PASSWORDS` 或者当前用户角色为 `ADMIN_USER_ROLE`，否则不允许访问管理后台。

## 批量创建邮箱与导出登录链接

在 **管理后台 → 邮箱管理 → 创建邮箱** 中，将创建方式从默认的 **单个创建** 切换为 **批量创建**。选择域名、前缀及可选的随机或自定义子域名，输入 **1–100** 的整数数量（默认 10），点击 **批量创建**。浏览器为每个邮箱生成随机名称；单个模式显示名称输入框，批量模式显示数量输入框，两个模式共用域名设置。

创建请求按顺序执行，并显示已完成数量与请求数量。请求失败时立即停止，不自动重试，保留已确认成功的记录。中断的请求可能已经创建邮箱，结果未知；再次创建前请检查邮箱列表。离开页面后不会继续发送后续创建请求。

点击 **导出 CSV** 打开导出弹窗，选择格式后点击 **下载 CSV** 下载 UTF-8 文件，仅包含 `address` 和 `login_url` 两列，链接可在当前前端自动登录对应邮箱。连续批次的成功记录会累积，切换创建方式不会清空，直到点击 **清空结果** 或离开页面；记录仅保存在内存中。创建期间无法切换创建方式、修改公共设置、导出或清空。

- **电子表格安全 CSV**（`mailbox-login-links.csv`）：用于 Excel 或 Google 表格。以 `=`、`+`、`-`、`@`、制表符或回车开头的单元格（例如使用此类 `PREFIX` 的地址）会在前面加上 `'`，以便表格软件将其作为文本显示。程序读取此文件时，`'` 会成为值的一部分。
- **无损 CSV**（`mailbox-login-links-raw.csv`）：用于脚本和程序。仅使用标准 CSV 转义，CSV 解析器读取到的地址和登录链接与原值一致。如果地址以上述字符开头，请勿用表格软件打开。

任何持有登录链接的人都可访问对应邮箱。请将 CSV 视为邮箱凭据并私下分发。私有部署仍需要原有的站点访问凭据，导出文件不会包含这些凭据。

## 管理员密码和用户账号的区别

`ADMIN_PASSWORDS` 是管理后台的管理员密码，不是站点用户账号，也不对应某个邮箱地址。使用管理员密码登录后可以进入后台，但它本身不能收信。

站点用户账号存储在 `users` 表中，需要通过用户登录体系进入；用户是否能收信取决于是否创建或绑定了邮箱。即使你创建了一个用户邮箱为 `admin@example.com` 或用户名看起来像 `admin` 的普通用户，它也不会自动获得后台权限。

如果希望某个用户也能进入管理后台，请配置 `ADMIN_USER_ROLE`，并在用户管理中给该用户设置相同的角色。

## 统计 Dashboard

顶部 8 张卡片展示邮件、邮箱、用户和发件总数，以及过去 7 天和 30 天的活跃邮箱和用户数。活跃数按各记录的最后更新时间统计，注册和 OAuth 登录会更新用户记录，密码和通行密钥登录不会更新用户记录。邮箱域名筛选影响邮件、邮箱、活跃邮箱和发件，用户总数和活跃用户始终按全站统计。

「统计」页面通过统一的时间范围和邮箱域名筛选查看收件、新建邮箱、发件及新增用户折线图。点击右侧时间按钮选择今天、近 7 天、近 30 天或自定义日期；自定义范围最多 30 天，点击「应用」后生效。单日按小时展示，其余按天展示，均使用 UTC。图表使用懒加载的 ECharts，支持悬停联动与缩放。

域名选项取自配置的邮箱域名，不扫描邮件生成筛选选项。用户增长是全站统计，不受邮箱域名筛选影响。图表统计当前保留记录，已删除的数据不计入，也不代表净增长。

趋势只查询所选日期范围，并在 SQL 中直接筛选所选邮箱域名。统计加载结束后可以切换邮箱域名，页面沿用已加载的全站用户统计。手动刷新会重新查询用户统计，切换时间只查询趋势。

统计页使用 `GET /admin/statistics`。`from` 和 `to` 使用 UTC 零点格式 `YYYY-MM-DD 00:00:00`，结束时间不计入范围。可用 `domain` 筛选邮箱域名，并用 `includeTotals=true` 随趋势返回总量。无参数调用仍返回旧版总量字段。

数据库 v0.0.11 为邮箱域名统计增加索引。已有数据库可通过管理后台的数据库迁移启用索引。

## 邮箱列表排序

管理后台的「邮箱管理 → 邮箱列表」支持按列排序，可点击表头进行升序/降序排列：

- ID
- 邮箱地址
- 创建时间
- 更新时间
- 邮件数量
- 发送数量

搜索邮箱地址时，分页会自动重置到第 1 页。

`DISABLE_ADMIN_PASSWORD_CHECK = true`

## IP 黑名单 / 白名单

在管理后台的 **IP 黑名单设置** 页面可配置访问控制，作用于以下接口：创建邮箱地址、发送邮件、外部发送邮件 API、用户注册、验证码校验。

### IP 白名单（严格模式）

启用后，**仅**匹配白名单的 IP 才能访问受保护接口，其他所有 IP 一律返回 403。

- 纯文本条目：精确匹配（不支持子串），例如 `1.2.3.4`
- 正则条目：使用锚定正则，例如 `^192\.168\.1\.\d+$`
- 白名单命中的 IP 会跳过黑名单检查
- 白名单启用但列表为空时，服务端忽略该开关（防止锁死）

### IP 黑名单

启用后，匹配黑名单的 IP 返回 403。支持文本子串匹配或正则表达式。

### ASN 组织黑名单

按运营商/ISP 拉黑，不区分大小写，支持文本匹配或正则。

### 浏览器指纹黑名单

按 `x-fingerprint` 请求头拉黑，支持精确匹配或正则。

### 每日请求限流

限制单个 IP 每天最多请求次数（1–1,000,000），超出返回 429。计数以 UTC 日期为周期，24 小时后自动重置。
